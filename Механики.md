# GypsyAliens — механики MVP

Стелс-кооп прототип: инопланетяне проникают в дом, крадут животных и эвакуируются на тарелке, пока хозяин патрулирует и стреляет.

**Сеть:** Photon Fusion (Host). Уровень генерируется по общему `LevelSeed` у всех клиентов одинаково.

---

## Цель миссии

1. Оглушить / загнать кошек и собак.
2. Дотащить их в зону эвакуации у спавна.
3. Когда все животные украдены — всем игрокам встать в зону → победа.

---

## Игрок

| Действие | Управление |
|---|---|
| Ходьба | ЛКМ по полу (клик-путь по комнатам) |
| Прицел / бросок камня | Удержание Space → отпустить |
| Тащить животное | Space рядом с оглушённым / доступным NPC |
| Pause | Esc → Resume / Exit to Hub |

- Камень летит по параболе; стена на траектории блокирует бросок (красная кривая).
- Камень оглушает животных, хозяина и **других игроков** (~3.5 с).
- Попадание винтовки хозяина = смерть → респавн на старте (короткая неуязвимость).
- Стены у курсора полупрозрачны (X-ray); декор по периметру в X-ray не входит.

---

## Животные (кот / собака)

- Бродят по комнате; видят игрока конусом → убегают в соседнюю комнату (не в комнату с игроком).
- Слышат шум (камень, чужой drag) → убегают **от источника** (можно пасти броском).
- Свой шум при перетаскивании их не пугает.
- Оглушение камнем → можно тащить; несколько игроков могут тащить вместе.
- Собака тяжёлее кота (сильнее замедляет).
- Пока тащат и двигаются — непрерывный шум (хозяин может услышать).
- В зоне эвакуации животное улетает в тарелку.

---

## Хозяин дома

- Патрулирует комнаты (не заходит в стартовую без повода).
- Увидел игрока → тревога (`?`) → прицел → выстрел (`!`).
- Камень оглушает → после этого идёт к месту броска.
- Слышит шум → идёт расследовать.

---

## Шум

- Пульс при ударе камня (~4.5 м, ~1 с) + белые ripples.
- Шум от drag, пока носители реально двигаются.
- Реагируют хозяин и животные.

---

## Эвакуация

- Кольцо + тарелка над спавном.
- Drag в радиус → анимация подъёма, тарелка смещается к точке (реплицируется всем).
- HUD: прогресс «украдено / нужно».
- Победа: все животные извлечены **и** все игроки в зоне.

---

## Уровень

- Процедурные комнаты (Synty), двери 2 клетки, граф комнат для pathfinding.
- Декор у стен (детерминированно от сида) — коллайдеры есть, центр комнаты свободен.
- При выходе хоста клиент возвращается в меню подключения.

---

## Кооп-заметки

- Host / Join / Auto Host-Join, общее имя комнаты.
- Тест на одной машине: Editor + билд (или два билда).
- Пауза не ставит `timeScale` — симуляция для остальных продолжается.
